@startuml
title CD-06 UC-G16 Register Account

skinparam classAttributeIconSize 0
hide empty members

class RegisterPage <<boundary>> {
    + submit(e)
    + verify(token)
}

class AuthController <<boundary>> {
    + register(req, res)
    + verifyEmail(req, res)
    + validateBody(rules)
    + assertPasswordStrength(password)
    + signVerificationToken(userId) : String
    + record(entry)
}

class User <<entity>> {
    - _id : ObjectId
    - fullName : String
    - email : String
    - phone : String
    - passwordHash : String
    - status : AccountStatus
    - roles : ObjectId[]
    - emailVerifiedAt : Date
    - userType : String
    + findOne(filter) : Query<User>
    + create(fields) : Promise<User>
    + findByIdAndUpdate(id, update) : Query<User>
}

class EmailService <<external>> {
    + sendVerificationLink(to, token)
}

enum AccountStatus <<enumeration>> {
    PENDING_VERIFICATION
    ACTIVE
    LOCKED
    DEACTIVATED
}

RegisterPage ..> AuthController : POST /api/auth/register\nGET /api/auth/verify?token=
AuthController ..> User
AuthController ..> EmailService : verification link
User --> AccountStatus : status

note bottom of RegisterPage
    Includes the VerifyEmailPage continuation required by this use case.
    verify(token) is authApi.verify(), invoked by that page's effect.
end note

note bottom of AuthController
    Service and middleware operations are folded into this boundary.
    Role lookup, LoyaltyAccount.create() and audit writes are summarized
    in SD-06 to retain the assigned User-only model view.
    Loyalty account creation precedes email verification in the code.
end note

note bottom of User
    create(fields) is Customer.create(), the User discriminator,
    which inserts into the users collection with userType = Customer.
    The verification update does not check whether a user was found.
end note

note bottom of EmailService
    NotificationProxy.sendVerificationLink() represents this external call.
    Delivery errors are caught; registration still returns 201.
    Development without a configured provider logs the email.
end note
@enduml
