class AccountsPage <<boundary>> {
    + assignRole(id, roleId)
}

class AccountController <<boundary>> {
    + assignRole(req, res)
    + authenticate(req, res, next)
    + requirePermission(permission)
    + assertNoPrivilegeEscalation(actor, incoming, actorId)
    + assertNoSegregationConflict(current, incoming)
    + record(entry)
}

class User <<entity>> {
    - _id : ObjectId
    - email : String
    - status : AccountStatus
    - roles : ObjectId[]
    + findById(id) : Query<User>
    + populate(path) : Query<User>
    + save() : Promise<User>
    + findByIdAndUpdate(id, update) : Query<User>
}

class Role <<entity>> {
    - _id : ObjectId
    - name : RoleName
    - permissions : Permission[]
    + findById(id) : Query<Role>
}

class EmailService <<external>> {
    + sendDecisionNotice(to, subject, body)
}

    ACTIVE

AccountsPage ..> AccountController : POST /api/accounts/:id/roles
AccountController ..> User
AccountController ..> Role
AccountController ..> EmailService : access-change notice
User "0..*" -- "0..*" Role : roles
User --> AccountStatus : status
Role --> RoleName : name
Role --> Permission : permissions

note bottom of AccountsPage
    Includes AccountDrawer, whose mutation invokes adminApi.assignRole().
    Account and role-catalogue loading are preconditions from UC-A01/A05.
end note

note bottom of AccountController
    Service and middleware operations are folded into this boundary.
    record() summarizes AuditService.record().
    ADMIN and MANAGER are the implemented conflicting role pair.
    Only a SUPER_ADMIN may grant SUPER_ADMIN.
end note

note bottom of User
    populate() is a Mongoose query-chain operation.
    sessionsInvalidatedAt is not a schema field; its update is a stub.
    authenticate() does not enforce that timestamp against existing JWTs.
    expiresAt and reason are audit metadata, not assignment attributes.
    No automatic role-expiry scheduler is implemented.
end note

note bottom of EmailService
    NotificationProxy.sendDecisionNotice() represents this external call.
    Delivery errors are ignored; development may log the notice.
end note
