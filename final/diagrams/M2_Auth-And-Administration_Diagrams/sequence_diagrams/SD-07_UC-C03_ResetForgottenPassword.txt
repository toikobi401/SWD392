@startuml
title SD-07 UC-C03 Reset Forgotten Password

actor "Customer" as CU
boundary "ForgotPasswordPage" as UI
boundary "AuthController" as C
entity "User" as U
database "MongoDB" as DB
participant "Email service" as E

CU -> UI : enter email
activate CU
activate UI
UI -> C : request reset code
activate C
C -> U : save reset code for email
activate U
U -> DB : update user
activate DB
DB --> U : saved
deactivate DB
U --> C : done
deactivate U
C -> E : send reset code email
C --> UI : reset code sent
UI --> CU : ask for code and new password
CU -> UI : enter code and new password
UI -> C : submit new password
C -> C : validate request
C -> U : reset password with code
activate U
U -> DB : update password
activate DB
DB --> U : update result
deactivate DB
U --> C : result
deactivate U
alt code is valid
C --> UI : password changed
UI --> CU : go to login page
else code is wrong or expired
C --> UI : invalid reset code
UI --> CU : show error message
end
deactivate C
deactivate UI
deactivate CU
@enduml
